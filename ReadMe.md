### پروژه بازی Pac-Man - پروژه درس برنامه‌نویسی پیشرفته  
<h4 align="right">
این پروژه مربوط به بازی کلاسیک Pac-Man می‌باشد که با رعایت اصول شی‌گرایی (OOP) و با زبان جاوا نوشته شده است. 
</h4>
<a href="https://github.com/Nima07S/Pac-Man"> لینک ریپوی پروژه </a>

---

### نحوه نصب و راه‌اندازی (Setup)  
<ol align="right">
<li>ابتدا باید <b>JDK</b> (Java Development Kit) را نصب داشته باشید. نسخه ۲۵ و بالاتر پیشنهاد می‌شود. (<a href = "https://www.oracle.com/java/technologies/downloads/#java26">لینک دانلود از سایت اوراکل</a>)<br></li>
<li>IDE استفاده شده برای توسعه و پیشنهادی برای اجرای بازی <b>Visual Studio Code</b> است. (<a href = "https://code.visualstudio.com/download?_exp_download=fb315fc982">لینک دانلود از سایت مربوطه</a>)<br></li>
<li>فایل ZIP بازی را Extract کنید.<br></li>
<li>پیش از اجرای بازی، فونت مورد نیاز (<code dir="ltr">Emulogic-zrEw.ttf</code>) موجود در پوشه <b>font</b> را روی سیستم‌عامل خود نصب کنید تا نوشته‌های بازی به درستی نمایش داده شوند.</li>
<li>داخل برنامه vscode، قسمت EXTENSIONS عبارت <b>Extension Pack for Java</b> را که دارای ۶ افزونه مجزاست، را جست‌وجو، دانلود و نصب کنید.</li>
<li>منوی File را باز کنید، گزینه Open Folder را بزنید و پوشه  بازی را انتخاب کنید.</li>
<li>پوشه <b>Controller</b> را باز کنید و فایل <code>Main.java</code> را انتخاب کنید و تابع main را اجرا کنید انتخاب کنید.</li>
</ol>
